# mujoco_menagerie — 现实基准与结构说明

- **所属分类**：`05-DeepMind_MuJoCo_Menagerie_50款名机基准库_XML`
- **机型与功能简介**：Google DeepMind 官方维护的 50+ 款全球顶级机器人高精度 MJCF (.xml) 基准总库（含波士顿动力 Spot、Unitree、Franka、UR5e/10e、Shadow Hand、ANYmal B/C、Cassie、Apptronik Apollo、Talos 等）
- **开源上游地址 (GitHub)**：https://github.com/google-deepmind/mujoco_menagerie.git
- **首选现实基准文件（原件未二改）**：`google_barkour_vb/barkour_vb_rev_1_0_head_straight.urdf`
- **首选基准解析统计**：共 **35** 个刚体连杆 (`link/body`)，**34** 个运动关节 (`joint`)，示例关节：`abduction_front_left(revolute), abduction_hind_left(revolute), abduction_front_right(revolute), abduction_hind_right(revolute), hip_hind_right(revolute), hind_right_upper_leg_fixed_joint(fixed), knee_hind_right(revolute), hip_front_right(revolute)`
- **收录运动学基准文件数（`.urdf` / `.xml` / `.xacro` / `.sdf`）**：**270** 个
- **收录结构说明与配置文件数（`README` / `YAML` / 示意图）**：**440** 个
