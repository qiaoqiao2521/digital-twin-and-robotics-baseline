# ergocub-software — 现实基准与结构说明

- **所属分类**：`06-双足人形具身智能机器人`
- **机型与功能简介**：意大利技术研究院 IIT ergoCub 全尺寸双足人形具身智能机器人（含完整传感器与灵巧手 URDF）
- **开源上游地址 (GitHub)**：https://github.com/icub-tech-iit/ergocub-software.git
- **首选现实基准文件（原件未二改）**：`urdf/ergoCub/robots/ergoCubSN001/model.urdf`
- **首选基准解析统计**：共 **205** 个刚体连杆 (`link/body`)，**204** 个运动关节 (`joint`)，示例关节：`l_hip_pitch(revolute), r_hip_pitch(revolute), torso_roll(revolute), torso_pitch(revolute), torso_yaw(revolute), l_shoulder_pitch(revolute), r_shoulder_pitch(revolute), neck_fixed_joint(fixed)`
- **收录运动学基准文件数（`.urdf` / `.xml` / `.xacro` / `.sdf`）**：**73** 个
- **收录结构说明与配置文件数（`README` / `YAML` / 示意图）**：**56** 个
