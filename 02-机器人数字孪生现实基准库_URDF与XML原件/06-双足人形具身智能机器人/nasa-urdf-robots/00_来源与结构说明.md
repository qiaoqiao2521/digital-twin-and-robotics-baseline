# nasa-urdf-robots — 现实基准与结构说明

- **首选现实基准文件（原件未二改）**：`val_description/model/robots/valkyrie_sim_angled_legj1s.urdf`

- **收录结构说明与配置文件数（`README` / `YAML` / 示意图）**：**37** 个
